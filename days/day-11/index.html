AI Video Generation Agent — Architecture Specification

Báo Cáo Thiết Kế Hệ Thống AI Video Generation Agent

Hệ thống AI Agent thế hệ mới tự động hóa toàn bộ quy trình sản xuất video hoàn chỉnh từ natural language brief. Tích hợp kịch bản thông minh (LLM), tổng hợp giọng nói (TTS), đồng bộ môi (Lip-Sync), phân cảnh tự động (Scene Breakdown) và kết xuất GPU tốc độ cao.

Thời gian sinh video: < 90 giây Xử lý đồng thời: ≥ 100 Jobs Bảo mật: JWT + Signed URL Khả năng mở rộng: Horizontal Scaling Đánh giá tự động: AI Review Loop
Tổng Quan & Scope Chức Năng (FR1-FR11) Yêu Cầu Phi Chức Năng Kiến Trúc & Component Thiết Kế Database ERD Storyboard (8 Screens) Chi Phí & SLA Latency

01 Bài Toán, Mục Tiêu & Phạm Vi Hệ Thống

Vấn Đề (Problem Statement)

Quy trình sản xuất video truyền thống tốn nhiều thời gian và chi phí với 6 bước thủ công riêng biệt:

  • Viết script & sáng tạo kịch bản.
  • Phân chia phân cảnh (scenes).
  • Chọn Avatar & Diễn viên.
  • Ghi âm & lồng tiếng Voiceover.
  • Chỉnh sửa video, hiệu ứng, phụ đề.
  • Render & xuất file thủ công.

Giải Pháp AI Agent

AI Agent thực hiện toàn bộ quy trình khép kín chỉ từ 1 câu lệnh (Natural Language Brief):

  • Chuyển Brief thành Video MP4 hoàn chỉnh.
  • Giảm tối đa thao tác thủ công của con người.
  • Cho phép người dùng xem trước và chỉnh sửa linh hoạt.
  • Hỗ trợ xuất video 1080p sắc nét kèm Subtitle (.srt).
  • Mở rộng hạ tầng xử lý nhiều yêu cầu đồng thời.

Đối Tượng Sử Dụng (Users)

  • Marketing Teams: Tạo video quảng cáo nhanh (Facebook Ads, TikTok Ads, Landing Page Video).
  • Sales Teams: Tạo video giới thiệu sản phẩm, Demo giải pháp tự động.

Đầu Vào (Inputs)

  • Prompt / Brief bài viết hoặc yêu cầu.
  • Ngôn ngữ & Độ dài video mong muốn.
  • Optional: Avatar, Voice, Brand guideline, Logo.

Đầu Ra (Outputs)

  • Video MP4 (Chuẩn 1080p).
  • Subtitle File (.srt).
  • Script chi tiết & Ảnh Thumbnail.
  • Download URL & Share URL trực tiếp.

02 Yêu Cầu Chức Năng (Functional Requirements FR1 - FR11)

FR1 — Understand Brief

FR1

Đọc và phân tích prompt của người dùng. Trích xuất tự động các thuộc tính cốt lõi: Chủ đề, Mục tiêu, Đối tượng khán giả, Ngôn ngữ, Thời lượng video, Phong cách thể hiện.

FR2 — Generate Script

FR2

Sinh kịch bản thoại (narration) hoàn chỉnh bằng LLM. Đảm bảo tốc độ đọc và số lượng từ ngữ hoàn toàn khớp với tổng thời lượng được yêu cầu.

FR3 — Plan Scenes

FR3

Tách kịch bản thành các phân cảnh cụ thể với thời lượng đo đạc chính xác:
Intro (6s) → Feature 1 (12s) → Feature 2 (15s) → CTA (7s)
Mỗi scene quy định rõ: Narration text, Background type, Animation style, Subtitle timings.

FR4 — Select Avatar

FR4

Nếu người dùng không chỉ định Avatar, Agent sẽ tự động phân tích ngữ cảnh nội dung brief để đề xuất Avatar nhân vật có ngoại hình, giới tính, phong cách phù hợp nhất.

FR5 — Generate Voice

FR5

Sinh audio giọng đọc (Text-to-Speech) từ kịch bản script. Yêu cầu bắt buộc: Đúng ngôn ngữ, Đúng Accent (ngữ điệu địa phương/quốc gia), Tốc độ đọc tự nhiên.

FR6 — Lip Sync

FR6

Đồng bộ cử động môi và khuôn mặt Avatar theo tệp Audio vừa khởi tạo → Xuất kết quả Talking Avatar Video Component.

FR7 — Generate Scenes

FR7

Tạo tài nguyên hình ảnh và hoạt họa cho từng Scene bao gồm: Background image/video, Text overlays, Keyframe animations, Graphic images, Scene transition effects.

FR8 — Render Timeline

FR8

Ghép tổng hợp các thành phần: Talking Avatar + Background Audio/Music + Subtitle Stream + Transition Effects → Đưa vào Render Timeline xuất Video hoàn chỉnh.

FR9 — Review Loop (AI Self-Evaluation)

FR9

AI Agent tự kiểm tra chất lượng video trước khi xuất bản. Đánh giá các tiêu chí: Script quá dài? Subtitle vượt màn hình? Audio bị cắt cụt? Phân cảnh mất cân bằng? Nếu phát hiện lỗi → Tự động kích hoạt luồng Generate Lại Step Bị Lỗi.

FR10 — Export

FR10

Xuất gói sản phẩm hoàn chỉnh: File Video MP4 (Độ phân giải 1080p), File Subtitle chuẩn .SRT, và Thumbnail đại diện chất lượng cao.

FR11 — Publish

FR11

Lưu trữ tệp video vào Object Storage (AWS S3/Cloud Storage). Sinh Download URL (Direct Link) và Share URL để chia sẻ nhanh.

Thực Thi Công Nghệ & Mô Hình Thực Tế (Pragmatic Tech Stack)

Thành Phần (Component) Công Nghệ & API Đề Xuất Vai Trò & Lý Do Chọn (Phù Hợp Thực Tế)
1. Core Agent Orchestrator Python 3.11 + FastAPI Xây dựng RESTful API, quản lý State Machine dự án và điều phối tác vụ async bằng BackgroundTasks / Celery.
2. LLM Engine (Script & Plan) OpenAI GPT-4o / GPT-4o-mini Phân tích prompt người dùng, sinh kịch bản thoại và xuất dữ liệu JSON cấu trúc phân cảnh (Scene Breakdown).
3. Voice Synthesis (TTS) ElevenLabs API / Google Cloud TTS Chuyển đổi văn bản kịch bản thành tệp âm thanh (Audio MP3) chất lượng cao với ngữ điệu tự nhiên.
4. Lip-Sync & Avatar Engine D-ID API / HeyGen API (hoặc Wav2Lip Open-source) Tạo video nhân vật Avatar khớp cử động môi với file âm thanh TTS vừa tạo.
5. Timeline & Render Engine FFmpeg CLI + MoviePy (Python) Ghép nối các đoạn video cảnh, chèn Avatar, lồng tiếng, nhạc nền và phụ đề tự động thành file MP4 1080p.
6. Task Queue & Async Workers Redis + Celery (hoặc FastAPI BackgroundTasks) Quản lý danh sách tác vụ chờ render, giúp ứng dụng không bị tắc nghẽn (non-blocking) khi có nhiều yêu cầu.
7. Database & Object Storage PostgreSQL + AWS S3 / Supabase Storage Lưu trữ thông tin dự án, danh sách cảnh và tệp media xuất bản; tạo link tải an toàn bằng Presigned URLs.
8. Review Loop Check Thuật Toán Đếm Chỉ Số CPS (Characters Per Second) Kiểm tra độ dài câu thoại (>17 CPS trigger tự động chia dòng phụ đề hoặc yêu cầu LLM tóm tắt lại câu).

Chi Tiết Trách Nhiệm Thành Phần (Component Design)

Video Agent (Core Orchestrator)

  • Tiếp nhận Prompt & Brief từ Frontend.
  • Quản lý toàn bộ State Machine của Workflow bằng LangGraph.
  • Gọi GPT-4o / Claude 3.5 để phân tích và sinh kịch bản.
  • Kích hoạt các microservices render & tổng hợp kết quả.

LLM Engine

  • Phân tích ngữ nghĩa prompt & yêu cầu của người dùng.
  • Sinh script chi tiết phù hợp thời lượng target.
  • Tách phân cảnh (Scene Breakdown) & lập thời gian.

Asset Service

  • Cung cấp thư viện Avatar bằng LivePortrait / SadTalker.
  • Cung cấp giọng đọc TTS qua ElevenLabs API.
  • Quản lý kho nhạc nền (Background Music) & hiệu ứng.

Render Engine & Storage

  • Kết hợp video cảnh, talking avatar, phụ đề & audio bằng Remotion + FFmpeg.
  • Tận dụng phần cứng GPU (NVIDIA A10G) để render MP4 tốc độ cao.
  • Lưu trữ video đã xuất vào AWS S3 / Cloudflare R2 an toàn.

05 Thiết Kế Cơ Sở Dữ Liệu (Database Design)

Cấu trúc dữ liệu relational bao gồm 5 thực thể chính quản lý thông tin Người dùng, Dự án Video, Chi tiết Phân cảnh, Kho Avatar và Video Kết xuất.

Table: User
-- Lưu thông tin tài khoản & credits
id UUID PRIMARY KEY,
name VARCHAR(255),
email VARCHAR(255) UNIQUE,
subscription_plan VARCHAR(50),
credits INT DEFAULT 0,
created_at TIMESTAMP
Table: Project
-- Quản lý thông tin dự án video
id UUID PRIMARY KEY,
user_id UUID REFERENCES User(id),
title VARCHAR(255),
prompt TEXT,
language VARCHAR(10),
status VARCHAR(50), -- PENDING, RENDERING, COMPLETED
duration INT,
created_at TIMESTAMP,
updated_at TIMESTAMP
Table: Scene
-- Chi tiết từng phân cảnh trong video
id UUID PRIMARY KEY,
project_id UUID REFERENCES Project(id),
scene_order INT,
title VARCHAR(100),
narration TEXT,
duration INT,
background_type VARCHAR(50),
transition VARCHAR(50),
status VARCHAR(50)
Table: Avatar
-- Kho nhân vật Avatar của hệ thống
id UUID PRIMARY KEY,
name VARCHAR(100),
gender VARCHAR(20),
language VARCHAR(10),
thumbnail_url TEXT,
asset_url TEXT,
type VARCHAR(50),
status VARCHAR(20)
Table: Video (Output Deliverable)
-- Kết quả render video cuối cùng xuất bản
id UUID PRIMARY KEY, project_id UUID REFERENCES Project(id), video_url TEXT, thumbnail_url TEXT, duration INT, status VARCHAR(20)
