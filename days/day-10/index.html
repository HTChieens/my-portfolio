Ngày 10: SafeAgent Workspace - Architecture, Safety UX & State Persistence

Báo cáo công việc Ngày 10 bao gồm: Kiến trúc hệ thống tích hợp State Persistence (Lưu trữ trạng thái), Thiết kế Giao diện UX (4 màn hình), Luồng sử dụng chuẩn (Happy Path) và Các kịch bản Lỗi & Phá hoại (Failure & Abuse Cases).

1 Architecture (Hệ thống & State Persistence)

Mục tiêu: Giải thích AI làm việc ở đâu, các thành phần kết nối và cơ chế State Persistence lưu snapshot khôi phục dữ liệu khi ngắt kết nối.

User
  │
  ▼
Chat Interface
  │
  ▼
AI Agent
  │
  ▼
Cloud Sandbox
 ├─ Browser
 ├─ Python Runtime
 ├─ Workspace (Files)
 └─ Internet Access
  │
  ├──────► State Persistence (Auto Snapshot Workspace & Session DB)
  ▼
Result → User

Chat Interface

Nơi người dùng nhập yêu cầu và tải lên các tệp tin.

AI Agent

Hiểu yêu cầu và quyết định các bước chi tiết cần thực hiện.

Cloud Sandbox

Môi trường an toàn cô lập để chạy code, mở Browser và thao tác file.

State Persistence

Tự động chụp snapshot lưu biến code, file tạm và session state vào Persistent Volume/DB để khôi phục khi mất mạng hoặc timeout.

Result

Trả kết quả tóm tắt và tập tin đầu ra về cho người dùng.

4 Failure & Abuse Cases

1. Failure Cases (Lỗi Hệ Thống & Khôi Phục Trạng Thái State Persistence)

Tình Huống Lỗi UX Xử Lý & State Persistence Recovery
Code lỗi Hiển thị lỗi + Retry
Website không truy cập được Retry hoặc Skip
Sandbox hết thời gian Khôi phục trạng thái từ Snapshot gần nhất (Restore Workspace State)
Mất kết nối network Nối lại phiên (Resume Session) và nạp lại trạng thái từ State Persistence DB

2. Abuse Cases (Hành Vi Nguy Hiểm & Ngừa Phá Hoại)

Tình Huống Nguy Hiểm UX Xử Lý
Xóa nhiều file Yêu cầu người dùng xác nhận (Popup Permission)
Truy cập file nhạy cảm Chặn hoặc xin quyền
Chạy code quá lâu Tự động dừng (Timeout 120s) và lưu checkpoint trạng thái hiện tại
Tải file đáng ngờ Cảnh báo và chặn
