PAL Meta-Agent Evaluation Harness

Meta-agent trên MindPal/PAL dùng để tự động chạy agent khác, thu output, chấm điểm bằng rubric cố định và tạo báo cáo.

1. Deliverable

  • Working meta-agent: PAL Agent Evaluation Harness
  • Run history: replay một lần chạy hoàn chỉnh gồm 7 bước.
  • Grading rubric: rubric 100 điểm, chia theo 6 tiêu chí cố định.
  • Sample report: báo cáo mẫu từ 6 lượt chấm: 2 agent x 3 test case.

2. Cách workflow hoạt động

Load test suite -> Run target agents -> Collect outputs -> Grade outputs -> Compile report
  • Trigger: mở link workflow, nhập tên test và pass threshold, sau đó bấm run một lần trong PAL.
  • Collect output: workflow gom kết quả theo agent_name, case_id, input_prompt, actual_output.
  • Scoring: PAL Meta Grader chấm từng output bằng cùng một rubric, không sửa hoặc viết lại output.
  • Automation: sau trigger ban đầu, PAL tự đọc test suite, chạy 2 agent trên 3 test case, gom 6 output, chấm từng output và biên soạn báo cáo.

3. Test suite

Case Prompt Must include Must not include
TC01 Viết email follow-up cho khách B2B sau demo lời cảm ơn, bước tiếp theo, CTA bịa giá, hứa tính năng chưa có
TC02 Tóm tắt phản hồi khách hàng: "Giá cao nhưng support tốt" sentiment, pain point, recommendation kết luận hoàn toàn positive
TC03 Tạo plan launch 7 ngày cho sản phẩm SaaS Day 1-7, kênh, metric mô tả chung chung

4. Rubric chấm điểm

Tiêu chí Điểm Ghi chú
Task completion 25 Nếu thiếu must_include, điểm tối đa là 18.
Correctness 25 Nếu bịa thông tin quan trọng, điểm tối đa là 12.
Instruction following 20 Nếu có must_not_include, điểm tối đa là 10.
Usefulness 15 Đánh giá mức độ có thể dùng ngay.
Clarity 10 Đánh giá độ rõ ràng và tổ chức nội dung.
Safety 5 Nếu không có vấn đề an toàn, cho 5.

Tổng điểm = đúng tổng 6 tiêu chí. Điểm 100 chỉ dành cho output gần như hoàn hảo.
